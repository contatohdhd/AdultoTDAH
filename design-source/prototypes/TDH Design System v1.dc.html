03

Fundamentos

# Cor

{{ c.name }} {{ c.hex }} {{ c.use }}

A interface é neutra. Cor editorial só nos grifos; cor funcional só no azul de ação e foco; cor informativa só em imagens e gráficos.

# Tipografia

{{ t.sample }} {{ t.spec }}

Inter é a fonte predominante. IBM Plex Mono aparece só no logo, no #, no bloco de título, em valores numéricos e em rótulos de diagrama.

# Espaço e blocos

{{ s.v }}
  • Página em blocos de largura total, separados por 12 px, alternando branco e #F5F5F7.
  • Respiro vertical do bloco: 64–152 px, proporcional à tela (clamp).
  • Um assunto por bloco: rótulo, título, frase de apoio e até duas ações.
  • Coluna de leitura 680 px (≈ 68ch); margem lateral 20 px.
  • Título → texto: 64–144 px. Antes de cada h2 do artigo: 2,6 em.

# Linhas, raios e movimento

Linha curta 72 px · ferramentas, compartilhar
Linha dupla 3 px #8A8A8E · sempre com margem
Divisor 1 px #E3E3E6 · listas
{{ r.v }}
{{ r.use }}

Movimento só para revelar: grifo (900 ms), variação de cor do gráfico e giro do R1 (≈ 600 ms), oscilação do ponteiro após responder. Cada um roda uma vez. Com Reduzir movimento, tudo fica estático.
